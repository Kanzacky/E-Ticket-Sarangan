## SLIDE 4 — RANCANG BANGUN + DEMO *(P1 & P2)*
> **Mulai DEMO DI SINI**
> Alur: **Registrasi → Beli Tiket → QR Code → Validasi Scan → Ekonomi Lokal**

### DEMO 1 — WISATAWAN *(P1)*
1. Buka tab akun **wisatawan**
2. Pilih tiket (jenis, jumlah, tanggal kunjungan)
3. **Pembayaran digital** selesai
4. **Tiket QR Code** tampil di layar

### DEMO 2 — PETUGAS / SCAN BARCODE *(P2)*
1. Buka tab akun **petugas**
2. Menu pemindaian → **scan barcode** QR wisatawan
3. Sistem **validasi** → status sah/berlaku
4. Kunjungan **tercatat otomatis**

### DEMO 3 — ADMIN / MONITORING *(P1)*
1. Buka tab akun **admin**
2. **Dashboard monitoring**: kunjungan real-time, statistik, rekap penjualan
3. Semua data terintegrasi, siap utk evalusi

**Penutup demo (P2):** 3 peran satu platform, data real-time terhubung.
